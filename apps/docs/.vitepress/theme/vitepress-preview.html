DISTRIBU
-TRON

Weighted, plot-ready distribution statistics from a frequency table.

Hand it the output of a GROUP BY and read median, quantiles, histograms, box plots, ECDFs and KDEs straight off it. Zero runtime deps, ESM-only, TypeScript-first.

quickstart.ts
import { distribution, summary, quantile } from "distribu-tron";

// a frequency table — { value, weight }
const d = distribution([
  { value: 10, weight: 1203 },
  { value: 20, weight: 2310 },
  { value: 24, weight: 145 },
]);

quantile(d, 0.5);   // → 20  (weighted median)
summary(d);         // { n, mean, stdev, … }

Weighted by design

Every input is a { value, weight } table. Integer counts or fractional importance — no re-exploding into raw arrays.

Plot-ready arrays

Histograms, ECDFs and KDEs come out as plain arrays that feed straight into any charting grammar. No charting dep baked in.

~425× faster on tables

Reads aggregated input directly. A p50 from a 1,000-row table runs ~425× faster than expand-then-quantile.

ROLLUP grouping

group() builds one distribution per key with hierarchical subtotals and a grand total — like SQL WITH ROLLUP.

Numerically stable

Neumaier compensated summation keeps results honest at very large n, where naive accumulation quietly drifts.

Zero deps, ESM, typed

No runtime dependencies, import-only, TypeScript-first. Node ≥ 22. Tree-shakable free functions throughout.

Shape & density

Turn a prepared Distribution into plot-ready arrays — histograms, ECDFs and kernel density estimates.

Prepare once, read many

Build a Distribution with distribution(), then call these free functions against the same substrate. They never re-sort or re-aggregate.

histogram(d)#

A capped Freedman–Diaconis histogram with auto-bins. Weights are conserved per bin, and you can pass explicit edges. Each bin is { x0, x1, weight } — ready to render as bars.

kde(d)#

A windowed Epanechnikov kernel density estimate with Silverman bandwidth (override via silvermanBandwidth). Returns { x, density } sample points that overlay cleanly on the histogram.

ecdf(d) & methods#

The full shape-and-density surface. All functions read the same cumulative-weight substrate.

FunctionReturnsNotes
histogram(d){ x0, x1, weight }[]Capped FD bins; explicit edges supported
kde(d, opts){ x, density }[]Epanechnikov · Silverman bandwidth
ecdf(d){ x, p }[]Empirical CDF as a step series
cdf(d, x)numberWeighted CDF at a point
Reserved field names

Grouped helpers flatten the group key onto each row — don't name a grouping dimension after an output field (weight, x, density, n, min, max, median, depth). The key would overwrite it.
